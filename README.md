## What This App Does

A modern plant e-commerce website where users can:

- Browse a curated collection of premium houseplants
- View detailed product information including care instructions
- Add plants to shopping cart with full cart management
- Enjoy a responsive design that works on all devices
- Read plant care tips in the blog section

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```sh
git clone https://github.com/muhammad-awais-web-dev/leaf-cart-shop.git
```

2. Navigate to the project directory:
```sh
cd leaf-cart-shop
```

3. Install dependencies:
```sh
npm install
```

4. Start the development server:
```sh
npm run dev
```

The application will be available at `http://localhost:8080`

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Build for production
- `npm run preview` - Preview the production build
- `npm run lint` - Run ESLint

## Deployment

This project is configured for GitHub Pages deployment. To deploy:

```sh
npm run build
```

The built files will be in the `dist` directory.
